# Architecture decision records

`YYYY-MM-DD-<slug>.md`, template in `docs/templates/adr.md`. Status `accepted` records here are binding for every implementer.

- Decided with the user during `/make-prd` and `/break-prd-down`.
- Implementers may only **propose**: they write to `proposals/` on their branch; `/execute-next-step` asks the user to accept, reject, or defer after merging.
- Supersede rather than edit: a changed decision is a new ADR with `supersedes:` set.
